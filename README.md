## This Project Aims to Develop a Recommendation system


This project is an intelligent assessment recommender built using GenAI and FastAPI. It helps hiring managers quickly find relevant SHL tests based on job descriptions or natural language queries.

## 🚀 Features

- 🔍 Query-based or JD-text-based SHL test recommendation
- 🧠 Uses Sentence Transformers for semantic search
- 📊 Supports filters like duration
- 📈 Evaluation with Mean Recall@K and MAP@K
- 🌐 Web app (Streamlit) + API (FastAPI)
